# Changelog

## 1.0.0 (2026-11-11)

First release.

- `/handwrite` skill: builds a handwriting font from a filled-in template or any photo of handwriting, then writes described or uploaded documents in it as print-ready PDFs.
- Font: 7 rotating variants per character, about 265 characters including Greek, maths operators, arrows, super/subscripts and fractions; missing characters drawn to match the sample's stroke weight.
- Printable 2-page template (109 characters, 3 boxes each) read automatically from phone photos, any orientation.
- Documents: headings, paragraphs, lists, tables (with spanning rows), notes, multi-column layout, fit-to-page-count.
- Styles: pencil (graphite grain, pressure, varying hand-drawn line weight, optional smudges), pen, marker; optional ruled notebook lines and dotted column dividers.
- Fixed: the capital delta label on the template no longer prints blank.
